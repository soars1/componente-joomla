# Componente Joomla — Projetos do Portfólio

Componente educacional para cadastrar e exibir projetos em um portfólio Joomla.

## Objetivo

Criar o componente `com_projetos`, com gerenciamento no painel administrativo e uma listagem pública de projetos.

Cada projeto terá:

- Título
- Categoria
- Descrição
- Link do GitHub

O desenvolvimento começa no Joomla 5.4.10. A cada etapa, o código será versionado neste repositório.

## Etapas planejadas

1. Estrutura mínima do componente e manifesto de instalação.
2. Instalação local no Joomla e primeira tela administrativa.
3. Cadastro, edição e listagem de projetos.
4. Exibição dos projetos no site.
5. Validação e geração do pacote instalável `.zip`.

## Referência

- [Tutorial oficial de desenvolvimento de componentes para Joomla 5.4](https://manual.joomla.org/docs/5.4/building-extensions/components/component-development-tutorial/)

## Instalação

O pacote final será uma extensão Joomla em formato `.zip`, instalável pelo administrador do Joomla.
