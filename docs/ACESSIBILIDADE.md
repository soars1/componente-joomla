# Acessibilidade

## Página pública
- Preservar a hierarquia de títulos h1, h2 e h3.
- Usar listas semânticas para o conjunto de projetos.
- Garantir que links possam ser acionados por teclado.
- Exibir uma mensagem textual quando não houver projetos.
- Conferir contraste e foco visível com o template ativo.

## Teste manual
1. Navegar apenas com Tab e Shift+Tab.
2. Conferir nomes de links com leitor de tela.
3. Aumentar o zoom para 200% e 400%.
4. Testar a página em largura de 320 px.
5. Conferir a experiência sem CSS.

O resultado depende também do template Joomla em uso.
