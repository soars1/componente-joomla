# Instalação local

1. Preparar uma instalação de testes do Joomla 5.
2. Conferir os caminhos de `com_projetos/com_projetos.xml`.
3. Criar o ZIP com o manifesto na raiz do pacote.
4. Instalar pelo gerenciador de extensões.
5. Confirmar que a tabela `#__projetos` foi criada.
6. Abrir a página pública e verificar a listagem vazia.

O pacote ainda não foi validado em uma instalação real. Não usar em produção antes dos testes de instalação, permissões e atualização.
